## Which APK Should I Use?

| APK | Use this if... |
| --- | --- |
| `android-arm64` | You have a modern Android phone or tablet. This is the best choice for most users. |
| `android-arm` | You have an older 32-bit ARM Android device. |
| `android-x64` | You use an x64 Android device or emulator. |
| `universal` | You are not sure which architecture your device uses and want the safest fallback. |

## Install Notes

- If you are unsure, try `android-arm64` first.
- If that does not install on your device, use `universal`.
- You may need to allow installation from unknown sources in Android settings before opening the APK.
